## 📋 Quick Reference — Where to Use Each Prompt

| Prompt | Tool | Use Case |
|--------|------|----------|
| **Prompt 1** (First Frame Image) | Midjourney, DALL·E 3, Adobe Firefly | Generate the calm opening still image |
| **Prompt 2** (Last Frame Image) | Midjourney, DALL·E 3, Adobe Firefly | Generate the energetic closing still image |
| **Prompt 3** (Animation) | Kling AI, Runway Gen-3, Luma Dream Machine | Animate between the two frames |

### Tips for Best Results
- Generate **both image frames first**, then feed them as start/end frames into the video tool
- In **Kling AI**: Use "Image-to-Video" mode → upload Frame 1 as start image, Frame 2 as end image → paste Prompt 3 as the motion description
- In **Runway Gen-3**: Use "Image + Text to Video" → Frame 1 as reference image → paste Prompt 3
- In **Luma Dream Machine**: Use "Keyframe" mode → set Frame 1 and Frame 2 as keyframes → add Prompt 3 as guidance
- For **Midjourney**: Add `--ar 9:16 --v 6.1 --style raw` at the end of Prompts 1 and 2
- For **DALL·E 3**: Use the prompts as-is — they are formatted for direct input
